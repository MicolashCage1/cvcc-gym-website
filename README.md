# CVCC — Castro Valley Combat Club (website concept)

A one-page, motion-heavy gym website concept: boxing, jiu jitsu, kickboxing, judo, fitness and an open-gym weight room.

## Run it
No build step. Open `index.html` in Chrome or Edge, or serve the folder with any static host (GitHub Pages, Netlify, Vercel).

To publish free with GitHub Pages: repo **Settings → Pages → Deploy from a branch → main / root**.

## What's inside
- `index.html` — the whole site (HTML, CSS and a little vanilla JS for the schedule and "Build your week" picker)
- `media/` — background videos and photos

## Notes
- Scroll animations (card wheel, sticky panels, moving strips) use CSS scroll-driven animations: full effect in Chrome/Edge; other browsers show a static layout.
- Placeholders still to replace: gym name/logo ("CVCC" is a working name), prices, address, hours, contact, coach names and bios, class times.
- Footage: free stock clips from Mixkit (Mixkit License, free for commercial use) and judo photos from Pexels (Pexels License). BJJ slots currently use MMA grappling stand-ins.
- Coach portraits are AI-generated placeholders, not real coaches. Their shirts show third-party brand logos, so swap them for real photos before any promotional use.
